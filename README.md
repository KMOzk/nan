# Project nano-eerstejaars HU-project van Kenan Öz
#### Project nano is een app store waar de speler uit verschillende app keuzes kan kiezen in de CLI.
## Inhoud:
> Account systeem: U kunt inloggen of een account aanmaken.
> 
> Guesser: Raad het number ( 3 verschillende moeilijkheden ).
> 
> Galgje: Raad het wordt ( 3 verschillende moeilijkheden )
> 
> Animal facts: Je krijgt keuze van True of False om de animal fact te raden.
> 
> Weather guesser: Je voert de naam van een stad in en je moet raden hoeveel graden het is in de stad die je hebt ingevoerd.
> 
> Rekenmenen: Je kunt kiezen welke rekenopdracht je krijgt je kunt zelf kieze wat voor sommen je moet maken ( +, *, / ), hoeveel je er wilt maken of je kunt bekijken hoe je de vorige keer hebt gedaan.
